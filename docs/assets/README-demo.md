# Demo assets

A short GIF or screenshot of the Desktop → Gaming → Desktop flow belongs here.

Suggested filename: `demo.gif` (or `demo.png`).

Capture tips:

1. Record entering Gaming Mode via `Mod+Shift+G` (or `niri-shift-switch-to-gaming`).
2. Show Steam Big Picture / gamescope session briefly.
3. Exit with `Super+Shift+R` back to the desktop session.

Once you have a file, link it from the **Demo** section in the root [README.md](../../README.md).
